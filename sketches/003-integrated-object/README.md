## Variant: Integrated object

### Design stance
One continuous instrument surface where progress, render motion, and hardware telemetry share a single composition.

### Key choices
- Layout: dial overlaps the render field; telemetry sits on one baseline
- Typography: mixed-case Instrument Sans with only three sizes
- Color: warm black, off-white, one signal-orange progress accent
- Motion: slow ambient blades plus one measured activity trace

### Trade-offs
- Strong at: distinctive physical-object character and arm’s-length hierarchy
- Weak at: real preview imagery must be composed behind the dial rather than occupy a standalone rectangle

### Best for
- The production direction if the integrated field feels right on the physical panel
