## Variant: Object face

### Design stance
A tactile information object with one warm progress gesture and a contrasting measurement strip.

### Key choices
- Layout: progress-led asymmetric face
- Typography: mixed-case Instrument Sans
- Color: graphite, warm paper, signal orange, muted blue
- Motion: soft orbiting light and a restrained activity pulse

### Trade-offs
- Strong at: distinct physical-product character
- Weak at: light telemetry strip is brighter in a dark room

### Best for
- Strongest Teenage Engineering reference without imitation
